# HireHub – Job Board Portal

HireHub is a responsive and user-friendly Job Board Portal designed to connect job seekers with exciting career opportunities. It allows users to explore job listings, search and filter jobs based on role and location, and submit job applications through an easy-to-use application form.
The portal also includes an Admin Dashboard where administrators can add new job listings, manage existing jobs, and view submitted applications.
